# Contributor Covenant Code of Conduct

## Our pledge
We are committed to making participation in this project a welcoming, respectful, and harassment-free experience for everyone.

## Expected behavior
Be respectful, assume good faith, give constructive feedback, and focus on what is best for the community.

## Unacceptable behavior
Harassment, insults, doxxing, threats, and discriminatory conduct are not acceptable.

## Enforcement
Repository maintainers may edit or remove contributions that violate this code and may restrict participation when necessary. Report concerns privately to the repository maintainer.
